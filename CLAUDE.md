# Slotly — Claude Code Instructions

## Project

Slotly is a full-stack booking and business-management platform for service businesses.

It is designed to support:

- solo professionals
- independent specialists
- small studios and salons
- teams with different roles
- multi-location businesses

The platform will manage areas such as:

- businesses
- locations
- staff
- services
- schedules
- time off
- clients
- bookings

Customers should be able to see real availability and book services online.

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS

Backend:
- Node.js
- Express.js
- PostgreSQL
- `pg`

Authentication:
